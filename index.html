▶ THE STORY SO FAR

LEVEL 1

I started out curious about how things work under the hood. That led me to the University of Botswana, where I finished four years of Computer Science.

Along the way I picked up Rust, C, Java and Python, plus Red Hat and Cisco courses on Linux and cybersecurity.

LEVEL 2

Real-world mode. I spent seven months at Technology Affiliates Group doing data analysis, then joined Maru Quick, where I shipped a fintech mobile app and the USSD backend that lets feature phones use it.

That taught me the big lesson: software only counts when real people in Botswana can use it on real networks.

LEVEL 3

Now I focus on offline-first, distributed and privacy-first software. My final year project, ShieldMesh, lets phones send encrypted messages with no internet at all.

I also run Thebe Technologies, and I’m learning game development with Raylib because games are where all the fun problems live.

NEXT LEVEL

I’m looking for my next team. Somewhere I can ship things, learn fast, and keep building for places where connectivity is a luxury.
